# EcoDrive-Manager

Proyecto WPF de gestión logística en C# que simula rutas, paquetes y vehículos.

## Qué incluye

- WPF UI con paneles para vehículos, paquetes, rutas y resultados.
- Clases orientadas a objetos: vehículos, paquetes, rutas, algoritmo de logística.
- Estructuras dinámicas: lista enlazada genérica y grafo de rutas.
- Algoritmos recursivos para ordenar, buscar y calcular costos.

## Archivos principales

- `ConsoleApp1.csproj` - proyecto .NET 9.0 WPF.
- `Program.cs` - punto de entrada de la aplicación.
- `GUI/` - interfaz gráfica y lógica de interacción.
- `Core/` - modelos de dominio: vehículos y paquetes.
- `Data/` - implementaciones de estructuras dinámicas y grafo.

## Cómo ejecutar

1. Abre la carpeta `ConsoleApp1` en Visual Studio o VS Code.
2. Asegúrate de tener .NET 9 instalado.
3. Ejecuta el proyecto en modo WPF.

## Uso básico

- `Optimize Distribution` asigna paquetes a vehículos.
- `Sort Packages` ordena paquetes por peso.
- `Calculate Costs` muestra el costo total de envío.
- `Find Best Route` calcula la ruta más corta.
- `Generate Report` genera un informe resumen.
